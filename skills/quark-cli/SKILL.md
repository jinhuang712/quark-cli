# quark：夸克网盘命令行

`quark` 通过用户自己登录的本机 Chrome 操作夸克网盘。你是它的主要使用者，用户只在两件事上出场：扫码登录，和批准有风险的操作。

## 先看帮助

不确定的时候先运行 `quark --help`（总览）或 `quark <命令> --help`（用法、例子、会不会改动网盘、能不能撤销、可能的错误）。下文只是速查。

## 原则

- **每个命令只做一件事。** 不自动建目录，不自动跳过、覆盖或合并同名项，不弹出提问。需要几步就发几条命令。
- **路径都从网盘根目录写起**，例如 `/WORK/简历`。
- **失败时 stderr 有 `error`、`code`、`exit`、`next`。** 按 `next` 做；`code` 和退出码一一对应。

## 命令速查

带 * 的会改动网盘。

| 命令 | 做什么 |
|---|---|
| `login` | 弹二维码小窗，用户扫码（已登录会失败） |
| `whoami`、`logout` | 看账号、容量、会员；退出登录 |
| `ls [路径]` | 列文件夹，文件夹在前，新的在前 |
| `search <词>` | 全盘搜索，最多 50 条，`total` 是总数 |
| `info <路径>` | 看一个文件或文件夹的详情 |
| `mkdir <路径>` * | 建文件夹，上级一并建，已存在不算错（`changed: false`） |
| `mv <来源> <目标文件夹>` * | 移动，名字不变 |
| `rename <路径> <新名字>` * | 只改名字 |
| `rm <路径>... --yes` * | 删除，进回收站；不加 `--yes` 不会删 |
| `upload <本地路径> <网盘目录>` * | 传一个文件或文件夹到已有的网盘目录 |
| `download <网盘路径> <本地目录>` | 下载一个文件到已有的本地目录 |
| `share <路径>... [--days 1\|7\|30\|0] [--code]` * | 创建分享，默认 7 天，`0` 是永久 |
| `shares`、`unshare <链接>` * | 列出我的分享；取消一条 |
| `save <链接> <网盘目录> [--code 码]` * | 转存别人的分享到已有的网盘目录 |

## 输出

默认是 YAML，只有精简字段。选一个：`--json`（给 `jq`）、`--markdown`（给人看或贴报告）、`--raw`（只输出值，每行一个，用来接管道）。`--full` 输出夸克接口的全部字段，字段很多，别默认用。

用 `--raw` 把命令串起来：

```
quark search 临时 --raw | xargs quark rm            # 先看计划
quark ls /WORK --raw | head -3
```

## 必须先问用户的事

- **`rm`**：第一次不加 `--yes`。它不会删，会返回 `confirmation_required` 和 `plan`（路径、文件夹数、文件数）。把计划给用户看，**用户同意后**才加 `--yes` 重新运行。删除进夸克回收站，30 天内能找回，但回收站要客户端 3.1.3 以上，不要指望一定找得回来。
- **永久有效的分享（`--days 0`）**：链接是公开的，收不回来，先问。
- **`logout`**：会让用户重新扫码，先问。
- **分享链接和提取码**：分享出去等于公开，把链接给用户，不要自己发到别的地方。

## 常见错误怎么办

| `code` | 意思 | 你该做什么 |
|---|---|---|
| `not_logged_in`（3） | 没登录或登录过期 | 请用户运行 `quark login` 扫码，然后重试 |
| `already_logged_in` | 已经登录 | 直接用；要换账号先问用户再 `logout` |
| `not_found`（4） | 网盘路径或目录不存在 | 按 `next` 用 `quark ls` 看上一级；要建目录先 `mkdir` |
| `already_exists` | 目标处已有同名项 | 不要覆盖。先 `rename` 或 `rm`（`rm` 要问用户），或换个目录 |
| `confirmation_required`（2） | `rm` 没加 `--yes` | 把 `plan` 给用户看，同意后加 `--yes` |
| `refused`（5） | 夸克拒绝（账号受限、风控、转存自己的分享） | **不要重试**，把 `detail` 告诉用户 |
| `no_space` | 网盘容量不够 | 请用户清理空间 |
| `network` | 网络中断 | 重试；上传中途断了，按 `next` 的清理办法处理 |
| `share_gone`（4） | 分享链接已失效 | 请对方重新分享 |
| `bad_code`（4） | 提取码错或没给 | 用 `--code` 传入正确的提取码 |
| `usage`（2） | 命令用法不对 | 运行 `quark <命令> --help` |

## 常见流程

上传到一个新目录再分享：

```
quark mkdir /备份/2026
quark upload ./report.pdf /备份/2026
quark share /备份/2026/report.pdf --days 7 --raw
```

整理：先 `quark search`，再 `quark mv`，最后核对 `quark ls`。

## 注意

- 一次只传、只下载一个文件或文件夹。需要很多个，就多发几条命令。
- 下载只支持单个文件，不支持文件夹。
- 登录态保存在 `~/.quark-cli/profile`，等于账号密码，不要读它、不要复制、不要放进任何输出。
- 不绕过夸克的限速、风控或封禁；`refused` 就停下来。
